# INFO-2026-001｜数据结构分析

> 研究对象：Understanding Cat Care。主分类：编目型。原图由用户上传；作者、来源、版权未核实。不能将图片中无法可靠辨认的数字或文本当作已验证事实。

## 01 数据对象与粒度

- **案例级**：标题、主题、作者、发布时间、图像来源、版权许可、采集日期。
- **模块级**：基本信息、生命周期、耳部／眼部／胡须／行为、危险物品、尾巴语言、健康提醒、救助与领养流程、用品。
- **条目级**：每个行为姿态、用品、危险因素、流程步骤、身体部位对应一个记录。
- **图形编码级**：图标、标签、注释位置、颜色及连接关系记录。

## 02 字段建议

| 字段 | 类型 | 用途 | 备注 |
| --- | --- | --- | --- |
| case_id | 字符串 | 案例唯一ID | INFO-2026-001 |
| module_id | 字符串 | 主题模块ID | 防止重名 |
| module_name | 类别 | 如行为、用品、救助 | 按原图建立分类 |
| item_id | 字符串 | 条目ID | 用于关联图像及注释 |
| item_label | 字符串 | 图中原标签 | 不可辨认时标“待核” |
| item_description | 文本 | 条目说明 | 区分直接抄录与研究者解释 |
| value | 数值／空值 | 定量指标 | 须标记原图声称 |
| unit | 字符串／空值 | 数据单位 | 无法识别则留空 |
| stage_order | 整数／空值 | 阶段顺序 | 非严格时间线时不能赋真时间 |
| relation_target | 字符串／空值 | 关联身体部位／动作 | 关系不等于因果 |
| source | URL／文本 | 数据或图像来源 | 当前未核实 |
| verification_status | 枚举 | 已核实／待核实／无法辨认 | 明确质量 |
| rights_status | 枚举 | 已授权／未核实／受限 | 当前未核实 |

## 03 数据类型与映射

| 类型 | 原图区域 | 推荐表达 |
| --- | --- | --- |
| 类别型 | 耳朵姿态、尾巴、危险物品、用品 | 标签 + 图标或索引 |
| 顺序型 | 上部生命阶段、底部救助／领养 | 排序字段 + 步骤节点 |
| 定量型 | 年龄刻度与寿命类数字 | 值 + 单位 + 统计口径 |
| 关系型 | 身体部位及周围说明 | 图像区域—注释关系 |
| 文本型 | 英韩双语解释 | 语言代码 + 原文 + 翻译 |

## 04 数据风险

原图局部字体很小；寿命和年龄数据的定义、样本范围、资料来源尚无法核验。任何数字在取得原始出处前仅作为“图中主张”保存，不作为统计结论。流程步骤需与原图逐项复核。
