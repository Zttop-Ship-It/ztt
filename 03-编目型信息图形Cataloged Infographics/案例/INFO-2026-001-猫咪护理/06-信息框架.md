# INFO-2026-001｜信息框架分析

## 01 四层信息结构

1. **主题层**：UNDERSTANDING CAT CARE；副标题点明猫咪护理及流浪猫／家猫比较。
2. **比较层**：顶部两条弧形阶段路径，围绕不同猫咪生活状况展开。
3. **知识层**：基本信息、身体姿态与行为、危险物品、健康提醒等独立模块。
4. **行动层**：救助、领养流程以及底部用品准备。

## 02 空间布局

| 位置 | 模块 | 功能 |
| --- | --- | --- |
| 顶端 | 主标题、副标题 | 建立研究对象与阅读目标 |
| 左上—左中 | 基本信息、年龄、耳朵、眼睛、胡须、行为 | 基础知识检索 |
| 中部 | 大型猫咪插画、身体注释 | 视觉中心与结构说明 |
| 上部弧线 | 生命阶段路径、圆形步骤图标 | 阶段推进与对象比较 |
| 右侧 | 有害物品、尾部动作与健康提示 | 风险和行为识别 |
| 近底部 | Rescue／Adoption 流程 | 操作引导 |
| 最下部 | 猫咪用品陈列 | 资源准备 |

## 03 阅读策略

本图支持两种阅读方式：

- **总览式**：标题 → 大猫咪 → 两侧知识 → 底部行动；
- **检索式**：按模块标题直接定位耳朵、尾巴、风险、用品等局部内容。

两种路径同时存在，是编目型的主要特点；顶部和底部再插入局部线性顺序结构，形成混合式信息组织。

## 04 分类逻辑

主分类是主题编目，次级组织是阶段比较，局部形式是步骤说明。不能把主题模块之间的上下排列等同于严格父子结构，也不能把所有箭头等同于时间轴。

## 05 信息架构评价

优势：一张图集成多知识入口，利于展板式浏览。

挑战：类别数量多、视线跳转明显、节点语义可能不明确。可改进为统一模块编号、导览色标与可展开的数字化结构。

## 06 复用模板

标题区 → 中心主视觉 → 周边主题目录 → 关键比较或阶段模块 → 风险提示 → 行动流程 → 用品／来源区。
