## 新案例入库流程
1. 登记原始出处、作者、发布日期、采集日期和版权许可。
2. 根据案例分析报告模板拆解数据结构、统计图形及应用、视觉编码、信息框架、叙事框架。
3. 在案例索引中登记唯一 case_id 与主分类、交叉分类。
4. 新增案例后同步更新对应分类总文档。
5. 图片版权不明时明确标记未核实，不得宣称已获授权；公开仓库中只上传有权存储和传播的图像。

> “实时更新”指每次新增或修订案例时同步维护概念总文档；当前尚无无人值守自动更新机制。
