# ZTT 信息图形研究与案例知识库

本仓库依照**信息组织形式（五大类型）**和**常用表现形式（案例库）**双轨整理信息图案例。

## 五大信息图类型

- [编年型 Chronological](./01-%E7%BC%96%E5%B9%B4%E5%9E%8B%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2Chronological%20Infographics/)：时间线、事件顺序、持续时间、阶段和变化
- [层级型 Hierarchical](./02-%E5%B1%82%E7%BA%A7%E5%9E%8B%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2Hierarchical%20Infographics/)：父子关系、组织层级、分类树、权属与递进
- [编目型 Cataloged](./03-%E7%BC%96%E7%9B%AE%E5%9E%8B%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2Cataloged%20Infographics/)：集合、类别、属性、索引、比较与检索
- [字母表型 Alphabet](./04-%E5%AD%97%E6%AF%8D%E8%A1%A8%E5%9E%8B%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2Alphabet%20Infographics/)：以字母、拼音或指定字符序列构建索引
- [地理型 Geographical](./05-%E5%9C%B0%E7%90%86%E5%9B%BE%E5%BD%A2%E4%BF%A1%E6%81%AF%E5%9B%BE%E5%BD%A2Geographical%20Infographics/)：地点、地区、路径、分布、距离和空间关系

## 常用信息图形案例库
[常用信息图形案例库](./常用信息图形案例库/)包括词云图、HOW-TO、文字型信息图，每个子类按七个主题整理。

## 新案例入库流程
1. 在相应“案例”目录创建独立案例，先登记原始出处、作者、日期及版权许可。
2. 根据[案例分析报告模板](./案例分析报告模板.md)撰写独立分析报告，拆解数据结构、统计图形及应用、视觉编码、信息框架、叙事框架。
3. 在[案例索引.csv](./案例索引.csv)登记唯一 case_id，并记录交叉分类。
4. **同步更新所属分类的“01…概念及说明.md”**，注明新增证据、案例链接和更新日期。
5. 图片版权不明确时仅保留外链与来源记录，不上传受限原图。

> “实时更新”在本仓库指每次新增或修订案例时同步维护总文档；当前尚无无人值守自动更新机制。
